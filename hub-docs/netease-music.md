# 网易云音乐插件

在管理后台「意图识别」中启用「网易云音乐」，点击旁边的「设置」。保存网易云兼容 API 服务地址后，用网易云音乐 App 扫码登录。账号会话仅保存在网关 `data/netease-music-session.json`（0600），页面、模型、日志和设备客户端不会收到 Cookie。

插件只检索网易云并播放账号可完整收听的 MP3 在线音源。`exhigh` 为 320 kbps，`standard` 为标准音质。不启用解灰，不接其他平台，不播放 30 秒试听，也不保存音乐文件。

支持语音示例：

- 「播放陈奕迅的十年」
- 「搜索陈奕迅的歌曲」
- 「暂停音乐」「继续播放」「停止音乐」
- 「下一首」「上一首」：在本次搜索结果中切换，跳过不可完整播放的歌曲。

播放时唤醒小麦，音乐会暂停，让出麦克风和扬声器；本轮回复结束后继续。闹钟、提醒和铃声试听也会让音乐暂停。暂停指令会保持暂停，直到明确继续。首版不含收藏歌单管理、自动连播、歌词和断电续播。

后台提供扫码登录、登录检查、搜索和向在线设备发送播放控制。测试播放前先唤醒目标 ThinkSmart，使其连接到网关。多设备时请从目标设备的播放器按钮操作。启用本插件时，音乐点播统一由网易云插件处理；停用插件或切换到「不用插件」会停止播放。退出插件账号会删除本地会话，并停止所有在线设备上的音乐。

ThinkSmart 客户端需安装配套音乐组件并具有 ffmpeg。音乐解码至现有 48 kHz 双声道缓冲区，输出仍走 PipeWire，并进入现有回声消除参考；不会直接打开硬件 PCM。

本次部署的 API 服务运行在 Mac 上，通过仅允许 ThinkSmart 源 IP 访问的局域网端口提供服务。Mac 需登录、保持唤醒且与设备同网。接口地址变化后需重新配置、重新扫码，旧会话不会发往新接口。

自定义客户端版本为 `0.1.3+netease.1`。保留官方更新前的源码和回退点；直接更新到官方客户端／网关会覆盖本插件修改，应先回退或合并本功能。
